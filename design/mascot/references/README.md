# Mascot reference assets

Place approved visual references in this folder.

Suggested files:
- `concept-sheet.png`: approved visual concept sheet
- `original-sprite.png`: exported 32×32 Aseprite source
- `voxel-front.png`, `voxel-side.png`, `voxel-back.png`: production grid views

The current concept sheet is a style reference. It is not a strict voxel blueprint because the displayed geometry has not been validated against a fixed voxel grid.
